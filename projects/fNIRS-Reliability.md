# Reliability of fNIRS Signals

## Project Rationale

Functional near-infrared spectroscopy (fNIRS) is a promising neuroimaging technique that measures changes in the concentration of oxygenated and deoxygenated hemoglobin in the brain. Because it is quiet, tolerant of movement, and portable, fNIRS is far better suited than fMRI to working with children — which makes it attractive for the questions our lab asks about reading development.

Before we can use fNIRS to answer those questions, though, we need to know how much we can trust a single measurement. A brain measure is only useful as an individual marker if it is **reliable**: if the same person performs the same task on two different days, does fNIRS tell us the same story about their brain activity? Test–retest reliability is well characterized for some neuroimaging measures and poorly characterized for fNIRS, particularly for language tasks. If reliability turns out to be low, then differences between children that look like meaningful individual variation may be largely measurement noise.

## Project Description

Participants come to the lab on two occasions, one week apart, and perform the same reading task at each visit while we record fNIRS. Holding the person, the task, and the montage constant across sessions lets us ask directly how much of the signal is stable and how much varies from day to day. We quantify reliability both at the group level — does the task activate the same regions at both visits? — and, more demandingly, at the level of the individual participant, which is the level that matters if fNIRS is ever to be used as a marker of an individual child's reading development.
